# clamptrace

Clamp color trace values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/clamptrace/

## Install / run

```bash
git clone https://github.com/theworker02/clamptrace.git
cd clamptrace
node src/cli.js
node --test
```
